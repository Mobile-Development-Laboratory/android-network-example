# Пример работы с сетью в Android

Демонстрационный проект для сравнения трёх способов работы с HTTP в Android:

* **HttpURLConnection** (стандартный API Java)
* **Retrofit** (популярная библиотека поверх OkHttp)
* **Ktor Client** (асинхронный клиент от JetBrains)

Бонус: загрузка изображений через **Coil**

## Ветки

* `initial` – стартовый шаблон проекта без реализации
* `complete` – полностью реализованный пример со всеми подходами

## Используемое API

В проекте используется публичное API Amiibo: https://amiiboapi.com/

Оно предоставляет данные о персонажах и их изображениях, что удобно для демонстрации сетевых запросов и загрузки картинок
